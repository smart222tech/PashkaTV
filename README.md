# PashkaTV

A lightweight IPTV player for Android TV and Google TV.

## MVP features
- Load an M3U/M3U8 playlist from a URL
- Parse channel names and stream URLs
- Browse channels with a TV remote
- Play streams with AndroidX Media3 (ExoPlayer)

## Build
Open this project in Android Studio (Giraffe or newer) and let Gradle sync. Use JDK 17.

> Only add playlists and streams that you are authorized to access. PashkaTV does not provide channel lists or stream links.
